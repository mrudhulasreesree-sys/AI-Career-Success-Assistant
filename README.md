# 🎓 AI Career Success Assistant

An AI-powered Student Career Guidance System built using Python and Streamlit.

## Features

- Student Registration
- Student Login
- Student Dashboard
- Performance Prediction using Machine Learning
- Interview Questions
- CGPA Analysis
- Attendance Analysis
- Department Distribution

## Technologies Used

- Python
- Streamlit
- SQLite
- Scikit-learn
- Pandas
- Plotly

## Installation

```bash
git clone https://github.com/mrudhulasreesree-sys/AI-Career-Success-Assistant.git
cd AI-Career-Success-Assistant

pip install -r requirements.txt

streamlit run app.py
```
